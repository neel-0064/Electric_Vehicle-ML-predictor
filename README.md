# EV Population ML Predictor

End-to-end machine learning pipeline analyzing 1,200+ records of electric vehicle 
population data to identify key drivers of vehicle electric range.

**Live demo:** https://ev-ml-predictor-742874600981.us-central1.run.app/

## Stack
Python, Pandas, NumPy, scikit-learn, deployed on Google Cloud Run

## What it does
- Feature engineering and hyperparameter tuning to improve model fit
- Interactive data visualizations for exploring EV adoption trends
